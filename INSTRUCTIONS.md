## Troubleshooting

### If you see a blank page:
1. Open Chrome Developer Tools (F12 or Cmd+Option+I)
2. Click the "Console" tab
3. Look for any red error messages
4. Take a screenshot and share it

### If server stops working:
Double-click the file: `start-server.command`

### Alternative: Try the older version
If nothing works, try:
```
http://localhost:8080/q2-prototype-WORKING-BACKUP.html
```
This doesn't have the celebration feature but has all your other flows.
