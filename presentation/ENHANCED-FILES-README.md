## 🎨 Visual Design Elements Applied

### Colors & Branding
```
Primary Green: #024426 (HelloFresh dark green)
Primary Light: #067a46
Accent: #c8f542 (HelloFresh yellow)
Background: #FAFBFC
Cards: #FFFFFF with subtle shadows
Text: #1A1A2E (dark) / #6B7280 (muted)
Borders: #E5E7EB
```

### Typography
- **Font:** Inter (clean, professional, modern)
- **Hierarchy:**
  - Hero: 3.5rem bold
  - Sections: 2.5rem bold
  - Cards: 1.25rem semi-bold
  - Body: 1rem regular

### Card Styling
- White background
- 1px border (#E5E7EB)
- 16px border-radius
- Subtle shadow: `0 4px 20px rgba(0,0,0,0.05)`
- Hover lift effect: `translateY(-4px)`

### Sections
- Numbered sections: "01", "02", "03"
- Small uppercase labels with letter-spacing
- Generous padding (80px vertical)
- Alternating background colors (white / #F9FAFB)
