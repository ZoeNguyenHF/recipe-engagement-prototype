Feature Roadmap: Milestone Evolution

Timeline is defined with backend work; frontend is lightweight and can move fast. Features evolve from MVP to full scope experience.

Milestone 1 • 1-2 weeks

Foundation: Establish Trust

Problem

Users face decision paralysis with 20+ weekly recipes and lack trusted signals for confident meal selection.

Goal

Establish ratings as a reliable decision-making tool and create baseline rating behavior.

Track

Rating submission rate, time to menu completion, recipe trial rate (new vs repeat)

Signal

Success: Increased rating rate, faster menu completion. Risk: Low engagement, negative feedback dominance

Features

  • PDP top rating display
  • Overall rating section
  • Rating prompt banner
  • Community reviews (subset defined by cookbook)
  • User review card
  • Old rating drawer
Milestone 2 • 3-6 weeks

Insights: Deepen Understanding

Builds on M1

Problem

Users need more context beyond star ratings to understand why recipes are highly rated and what makes them work.

Goal

Provide deeper insights through distribution data, AI summaries, and thematic analysis to drive informed choices.

Track

AI summary engagement, theme click-through, rating distribution interaction, menu browse patterns

Signal

Success: Increased variety in selections, higher recipe trial rate. Risk: Information overload, AI summary trust issues

New Features

  • Rating distribution
  • AI summary CTA
  • Menu card showing ratings
Milestone 3 • 5-8 weeks

Filtering & Discovery

Builds on M1 + M2

Problem

Users want to find recipes matching specific preferences and filter by ratings, but lack tools to efficiently discover what they're looking for.

Goal

Enable self-service discovery through rating filters, comment themes, and improved rating UX to match personal preferences.

Track

Filter usage, rating completion rate (new drawer), menu filter adoption, comment theme engagement

Signal

Success: Higher satisfaction scores, reduced skip rate. Risk: Filter bias creates echo chamber, complex UI reduces adoption

New Features

  • Community reviews (new logic for subset)
  • Comment themes in review cards
  • Filters for rating
  • New rating drawer
  • Menu filters
Milestone 4 • 3-6 weeks

Rich Content: Enhanced Personalization

Builds on M1 + M2 + M3

Problem

Users want deeper thematic insights and visual proof before selecting recipes, but lack comprehensive filtering and enhanced AI understanding.

Goal

Provide rich visual content, comprehensive theme filtering, and improved AI summarization to enable confident, personalized recipe discovery.

Track

Photo review engagement, theme filter usage, theme overview interaction, AI summary quality metrics, recipe trial diversity

Signal

Success: Increased variety in selections, higher recipe trial rate. Risk: Photo requirements slow submissions, theme complexity confuses users

New Features

  • Theme overview
  • Filter for themes
  • Use photo captured from cookbook flow
  • Updated AI overview (improved comment summarization logic)
Milestone 5 • Data-driven

Community Engagement

Defined based on user engagement data

Problem

To be determined based on M1-M4 performance data and observed user engagement patterns.

Goal

Enhance community quality and reduce noise through moderation tools and engagement mechanics. Scope and features determined by user engagement data and decision to scale up or not.

Track

Review quality metrics, spam/fake review reports, helpful button usage, community moderation effectiveness

Signal

Success: Improved review quality perception, reduced support tickets. Risk: Over-moderation dampens honest feedback

Potential Features

  • Helpful/Report buttons
  • Photo from recipe feedback
  • Engagement feature, rating for addon, etc.
